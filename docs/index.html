Nmap Terrain Analyzer

A Dockerized workspace for building safe Nmap scans, retaining accountable evidence, and turning current or historical XML into useful terrain analysis.

Phase 1 + 2Roadmap
One scan pageBuild a scan once, then save its profile, run it now, or generate a portable package.
Reproducible profilesProtected templates, cloning, and immutable versions keep historical and scheduled coverage trustworthy.
TCP + UDPIndependent common, full, custom, and conservative ICS-focused port scopes with mandatory -n.
Full historical analysisPrevious scans reopen through the same host, service, identity, MAC, and outlier renderer used for uploads.
Useful exportsKeep host summaries or export one normalized CSV row per IP, protocol, and port.
AccountabilityFriendly names, creator/scheduler/executor metadata, immutable IDs, coverage, and retained PCAP evidence.

Phase 1 + 2 implementation

HistoryUnified historical/new-upload analysis, raw XML as a secondary action, and explicit coverage metadata.
IdentityName_Date_Time naming, visible (S) scheduled marker, and creator/scheduler/executor provenance.
ProfilesSave, clone, reuse, and save-as-new-version behavior with schedule definitions pinned to a version.
ScanningTCP, UDP, or TCP + UDP with independent port scopes and an ICS Safe Discovery template.

Later phases

Recurring scheduled execution, FPING discovery, traceroute and hop-path history, richer scan comparison, ARP/PCAP/OUI enrichment, SearchSploit/ExploitDB references, parser and network-mapping evaluation, and redesigned zero-touch device configuration collection.

GitHub Pages hosts this project page only. The FastAPI application and Nmap execution remain self-hosted through Docker because Pages cannot run server-side Python or network scanners.
