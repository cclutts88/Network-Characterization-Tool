### 2026-10-08 — Reach, Nmap presence, import, and saved-scan preparation

- **#6:** Completed Reach assessments now begin with a short reading sequence:
  outcome, likely path, retained evidence, then limits and uncertainty. Evidence cards
  are presented in that reading order without claiming that it is a universal packet-
  processing order. The novice workflow review and disposable browser assessment both
  confirmed the result is easier to follow.
- **#11:** Nmap `user-set` is explained as assumed reachability from `-Pn` when no
  direct response was retained. A stronger retained presence detail takes precedence,
  and CSV export keeps both the readable explanation and the raw Nmap reason for
  traceability. Focused analysis and export regressions passed in Docker.
- **#28:** The manual workspace is now **Import & investigate**. Its action says
  **Import and open this result**, then keeps the imported result visible while the
  optional Network Scope assignment remains available below. The novice workflow
  review and disposable browser preview confirmed the flow and wording.
- **#29:** Scan History now says **Prepare from saved scan** and explains that it uses
  the exact retained `scan.xml`, stays on the same history row, never reruns Nmap, and
  never contacts the network. The guide and System Health text use the same wording.

  primary focused Docker suite **101 passed**; complete Docker suite **1,010 passed,
  7 skipped**; diff checks passed.
